# AI služba, kterou lze prodávat v Česku

Tento repozitář obsahuje praktický průzkum příležitostí pro **automatizovanou AI službu** bez e-shopu. Výstup odděluje doložená data od hypotéz, porovnává sedm nápadů a převádí vítězný koncept do 30denního validačního plánu.

## Doporučení v jedné větě

Začněte jako úzce zaměřená služba **„AI recepční pro zmeškané hovory“** pro autoservisy, řemeslníky nebo menší servisní firmy: odpoví na běžné dotazy, získá kontakt a důvod volání, nabídne termín a složitý případ předá člověku.

Neprodávejte „AI“. Prodávejte měřitelný výsledek: **více zachráněných poptávek a méně vyrušování při práci**.

## Jak s výstupem pracovat

1. Vyberte jedinou vertikálu a jediné město nebo kraj.
2. Nejdříve prodejte ručně obsloužený pilot, teprve potom stavte plnou automatizaci.
3. Měřte počet zachycených relevantních poptávek, rezervací, předání člověku a chyb.
4. Po 30 dnech pokračujte jen tehdy, pokud zákazník vidí návratnost a chce platit pravidelný paušál.
